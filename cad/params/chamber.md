# 챔버 파라미터 대장

`chamber.txt`의 전역 변수 하나하나에 대해 값과 상태와 근거를 적는다. 상태 어휘는 `fixed` · `dependent` · `unknown` 셋이며 뜻은 `cad/README.md`에 있다.

값을 채울 때는 근거를 함께 적는다. 근거는 위키에 이미 서술된 사실이거나 사용자가 직접 결정한 값이어야 하고, 후자는 `사용자 결정 2026-09-10`처럼 결정한 날을 적는다.

## 위키가 확정한 형상 제약

수치는 아니지만 형상을 구속하는 사실들이다. 출처는 전부 `wiki/topics/모의장치.md`다.

| 제약 | 상태 |
|---|---|
| 도어를 통해 열고 닫을 수 있다 | fixed (사용자 확인 2026-09-04) |
| 시험은 밀폐 상태로 진행한다 | fixed (사용자 확인 2026-09-07) |
| SEN55 3대를 챔버 내부에 직접 노출되도록 둔다 | fixed (사용자 확인 2026-09-07) |
| ESP32-S3-WROOM-1과 PCA9548A는 챔버 상단 외부에 둔다 | fixed (사용자 확인 2026-09-07) |
| 전원과 통신은 USB 하나로 통합한다 | fixed (사용자 확인 2026-09-07) |
| 다섯 조건을 가습기 · 청소기 · 송풍기 · DEC 분사 · 열풍기로 조성한다 | fixed (정량적 성과지표 항목표) |
| 조건 사이에 이전 조건을 빼내는 환기 절차가 필요하다 | fixed (사용자 확인 2026-09-07) |
| 카메라는 이 장치와 별개의 장비다 | fixed (사용자 확인 2026-09-04) |

두 제약이 서로 당긴다. 전장이 챔버 상단 외부이고 SEN55는 챔버 내부이므로 I2C 배선이 챔버 벽을 가로지르며, SEN5x 데이터시트의 10 cm 미만 권고를 넘기기 쉽다. 케이블 관통 위치와 센서 위치를 정할 때 이 거리가 함께 결정된다.

## 아직 정해지지 않은 값

챔버의 mm 단위 치수는 한 개도 확정되어 있지 않다. 위키는 장치의 구성과 제약을 서술하지만 치수를 담고 있지 않으므로, 아래 항목은 사용자 결정이나 새 원문의 인제스트를 기다린다.

| 변수 | 뜻 | 상태 | 정해지려면 |
|---|---|---|---|
| `pack_W` `pack_D` `pack_H` `pack_N` | 시료 팩의 외형 치수와 수량 | unknown | 어느 팩을 넣을지 정하고 그 사양을 확인해야 한다. 다른 모든 치수의 출발점이다 |
| `clr_*` | 팩 둘레 여섯 방향의 여유 | unknown | 기류 회전 공간, 상부 감지 공간, 반입 작업 공간을 어떻게 볼지에 대한 결정 |
| `W_in` `D_in` `H_in` | 내부 유효 치수 | dependent | 팩 치수 + 여유 |
| `t_wall` | 판재 두께 | unknown | 재질과 함께 결정 |
| `W_out` `D_out` `H_out` | 외형 치수 | dependent | 내부 유효 + 양면 판 두께 |
| 재질 · 밀폐 등급 | 판재 재질과 IP 등급 | unknown | DEC 분무와 열풍에 견디는 조건 |
| `door_W` `door_H` | 도어 개구 | unknown | 팩 폭·높이에 반입 지그 여유를 더해 정한다 |
| 도어 개폐 방향 · 핸들 형식 | 경첩 위치와 래치 방식 | unknown | 밀폐 등급을 만족하는 압착 방식 |
| `handle_L` `handle_offset` | 핸들 길이와 안쪽 오프셋 | unknown | 핸들 형식이 정해진 뒤 |
| `win_W` `win_H` `win_z` | 관찰창 크기와 바닥에서의 높이 | unknown | 카메라가 무엇을 봐야 하는지에 달렸다 |
| 관찰창 재질 · 두께 | 내열 · 내화학 사양 | unknown | 조건 4·5의 실제 도달 온도 |
| `frame_H` | 받침 프레임 높이 | unknown | 사람 결정 |
| 포트 위치 3종 | 공용 주입 · 배기 · 케이블 관통의 면과 높이 | unknown | 주입과 배기의 관류 방향, 케이블 경로 |
| `inlet_dia` `exhaust_dia` | 주입 · 배기 구경 | dependent | 자극 장비의 실제 토출구, 요구 유량, 압력손실, 누설 시험 결과 |
| `cable_dia` | 케이블 관통 구경 | dependent | 선정된 케이블의 외경 |
| `sen_L` `sen_W` `sen_T` | SEN55 모듈 외형 | unknown | SEN5x 데이터시트가 담고 있는 값이다. `wiki/topics/SEN55.md`에 외형 치수를 인제스트해 넣으면 바로 확정된다 |
| SEN55 배치 형태 | 3대를 챔버 안 어디에 어떤 형태로 둘지 | unknown | 사람 결정. 위키는 3대라는 것과 내부 노출만 확정한다 |
| `sen_gap` | 부착면에서 모듈을 띄우는 거리 | unknown | 브래킷 형상과 함께 결정 |
| `elec_W` `elec_D` `elec_H` | 상판 외부 전장 공간 | unknown | 전장함을 선정하거나 확보할 공간을 먼저 정한다 |

`pack_*`이 첫 단추다. 팩 치수가 정해지면 여유를 얹어 내부 유효 치수가 나오고, 판 두께를 얹어 외형이 나오고, 도어 개구가 팩과 반입 여유에서 나온다. 이 사슬의 맨 위가 비어 있는 동안에는 어떤 스케치도 시작할 수 없다.

# 지표 3 모의장치 구성 부품

정량적 성과지표 지표 3의 검수 시연용 모의장치를 이루는 부품과, 부품마다 만들 CAD 파일을 정리한다. 장치가 무엇이고 왜 이렇게 구성되는지는 `wiki/topics/모의장치.md`가, 파일 배치와 이름 규칙은 `cad/CLAUDE.md`가, 치수의 상태와 근거는 `cad/chamber.md`가 담는다.

장치 밖에서 쓰는 것은 여기 넣지 않는다. 조건을 만드는 가습기·청소기·송풍기·DEC 분사 장비·열풍기, 별도 장비인 카메라, PC, 계측기는 모의장치의 구성 부품이 아니다.

## 형상 출처와 상태

형상 출처는 둘이다. **모델링**은 `src/<이름>.py`로 직접 만들어 `step/<이름>.step`을 낸다. **벤더 STEP**은 제조사가 배포한 STEP을 `step/imported/`에 원본 파일명 그대로 둔다.

| 상태 | 뜻 |
|---|---|
| 모델링 가능 | 형상을 정할 근거가 갖춰졌다 |
| 치수 미정 | 부품은 정해졌지만 형상을 정할 치수가 `cad/chamber.md`에서 `unknown` 또는 `dependent`다 |
| STEP 미확보 | 벤더 STEP을 쓸 부품인데 아직 받지 않았다 |
| 확보 | 벤더 STEP을 받아 `step/imported/`에 두었다 |

## 챔버 본체

사슬의 맨 위인 더미 팩 외형은 확정되었고, 다음 단추인 팩 둘레 여유가 비어 있어 내부 치수가 나오지 않는다 (`cad/chamber.md`). 도어 판 전체를 아크릴로 하므로 관찰창을 따로 두지 않고, 받침 프레임 없이 캐스터를 바닥 프로파일에 직접 단다 (사용자 결정 2026-10-06).

PCA9548A, 외부측 P82B715, 풀업 저항, 3.3 V 공급 소자는 전장 기판 위의 소자이므로 따로 CAD 파일을 두지 않는다. 기판 외곽이 정해지면 기판 모델 안에서 다룬다.

차폐 케이블을 쓸지는 아직 정해지지 않았다 (`wiki/topics/P82B715.md`, 사용자 확인 2026-09-07). 형상 부품이 아니므로 관통부 구경에만 영향을 준다.

## 모델링을 시작하려면

- 팩 둘레 여유를 정한다. 외함 골조·패널·도어·포트 높이·SEN55 반지름이 모두 여기서 나오는 내부 치수를 따라간다.
- 밀폐 등급을 정한다.
- 경첩·토글 클램프·손잡이·캐스터의 모델을 정한다.
- SEN55 외형 치수는 `wiki/topics/SEN55.md`에 인제스트되어야 브래킷 치수의 근거가 된다. SEN55 케이블측 커넥터(ACES 51452-006H0H0-001) STEP도 제조사에서 받는다.
- SEN55의 천장 크기 대비 반지름, 기준 방향, 천장 이격과 케이블 관통 위치를 정한다.
- 포트 구경을 정한다.
- 자체 PCB와 P82B715 센서측 기판의 외곽을 정한다.

# 챔버 파라미터 대장

챔버 치수 하나하나에 대해 값과 상태와 근거를 적는다. 아래 표의 변수명은 `src/params.py`의 상수명과 같게 쓴다. 상태 어휘는 셋이다.

- `fixed` — 근거와 함께 확정된 값. `src/params.py`에 상수로 들어간다.
- `dependent` — 아직 값은 없지만 무엇이 정해지면 따라 정해지는지가 분명한 값. `src/params.py`에는 다른 상수로 계산하는 식으로 들어가고, 수치를 지어내지 않는다.
- `unknown` — 근거도 종속 조건도 아직 없는 값. 결정을 기다리며 `src/params.py`에 넣지 않는다.

값을 채울 때는 근거를 함께 적는다. 근거는 위키에 이미 서술된 사실이거나 사용자가 직접 결정한 값이어야 하고, 후자는 `사용자 결정 2026-09-10`처럼 결정한 날을 적는다.

## 위키가 확정한 형상 제약

수치는 아니지만 형상을 구속하는 사실들이다. 출처는 전부 `wiki/topics/모의장치.md`다.

| 제약 | 상태 |
|---|---|
| 도어를 통해 열고 닫을 수 있다 | fixed (사용자 확인 2026-09-04) |
| 시험은 밀폐 상태로 진행한다 | fixed (사용자 확인 2026-09-07) |
| SEN55 3대를 챔버 내부에 직접 노출되도록 둔다 | fixed (사용자 확인 2026-09-07) |
| ESP32-S3-WROOM-1과 PCA9548A는 챔버 상단 외부에 둔다 | fixed (사용자 확인 2026-09-07) |
| 전원과 통신은 USB 하나로 통합한다 | fixed (사용자 확인 2026-09-07) |
| 다섯 조건을 가습기 · 청소기 · 송풍기 · DEC 분사 · 열풍기로 조성한다 | fixed (정량적 성과지표 항목표) |
| 조건 사이에 이전 조건을 빼내는 환기 절차가 필요하다 | fixed (사용자 확인 2026-09-07) |
| 카메라는 이 장치와 별개의 장비다 | fixed (사용자 확인 2026-09-04) |

두 제약이 서로 당긴다. 전장이 챔버 상단 외부이고 SEN55는 챔버 내부이므로 I2C 배선이 챔버 벽을 가로지르며, SEN5x 데이터시트의 10 cm 미만 권고를 넘기기 쉽다. 케이블 관통 위치와 센서 위치를 정할 때 이 거리가 함께 결정된다.

## 사용자가 결정한 형상

위키에 없는 형상 결정이다. 근거는 전부 사용자 결정 2026-10-06이다.

| 결정 | 상태 |
|---|---|
| 시료 팩은 실제 배터리가 아니라 외형만 본뜬 더미다 | fixed |
| 외함은 알루미늄 프로파일 3030 골조에 알루미늄 복합판 패널을 끼운다 | fixed |
| 받침 프레임 없이 바닥 프로파일에 캐스터 4개를 직접 단다 | fixed |
| 도어는 앞면 여닫이이고, 경첩은 앞에서 보아 오른쪽에 단다 | fixed |
| 도어는 토글 클램프로 밀폐재에 눌러 잠근다 | fixed |
| 도어 판 전체를 아크릴로 하고 관찰창을 따로 두지 않는다. 카메라와 그 고정부는 만들지 않는다 | fixed |
| SEN55 3대는 천장에 두고, 천장 중심에서 같은 거리에 120° 간격으로 대칭 배치한다 | fixed |
| 공용 주입 포트는 앞에서 보아 오른쪽 옆면, 배기 포트는 왼쪽 옆면에 마주 보게 둔다 | fixed |
| 전장 기판은 자체 PCB다 | fixed |
| P82B715 버스 익스텐더를 쓴다 | fixed |

## 아직 정해지지 않은 값

챔버의 mm 단위 치수는 프로파일 규격 하나만 확정되어 있다. 위키는 장치의 구성과 제약을 서술하지만 치수를 담고 있지 않으므로, 아래 항목은 사용자 결정이나 새 원문의 인제스트를 기다린다.

| 변수 | 뜻 | 상태 | 정해지려면 |
|---|---|---|---|
| `pack_W` `pack_D` `pack_H` `pack_N` | 더미 팩의 외형 치수와 수량 | unknown | 더미가 본뜰 외형과 수량을 정해야 한다. 다른 모든 치수의 출발점이다 |
| `clr_*` | 팩 둘레 여섯 방향의 여유 | unknown | 기류 회전 공간, 상부 감지 공간, 반입 작업 공간을 어떻게 볼지에 대한 결정 |
| `W_in` `D_in` `H_in` | 내부 유효 치수 | dependent | 팩 치수 + 여유 |
| `prof_W` | 골조 프로파일 단면 한 변 | fixed — 30 mm | 사용자 결정 2026-10-06 (3030 규격) |
| `t_panel` | 알루미늄 복합판 패널 두께 | unknown | 패널 제품을 정한다 |
| `W_out` `D_out` `H_out` | 외형 치수 | dependent | 내부 유효 치수 + 골조와 패널의 결합 방식 |
| 밀폐 등급 | 외함과 도어의 IP 등급 | unknown | DEC 분무와 열풍에 견디는 조건 |
| `door_W` `door_H` | 도어 개구 | unknown | 팩 폭·높이에 반입 지그 여유를 더해 정한다 |
| `t_door` | 아크릴 도어 판 두께 | unknown | 판 크기와 함께 결정. 조건 4·5의 실제 도달 온도를 재서 아크릴로 충분한지도 확인한다 |
| 경첩 개수 · 모델 | 오른쪽 경첩의 구성 | unknown | 도어 크기와 무게가 정해진 뒤 |
| 토글 클램프 개수 · 모델 | 도어 압착 | unknown | 밀폐재 압착에 필요한 힘과 도어 둘레 길이 |
| 도어 손잡이 | 토글 클램프와 별도로 손잡이를 둘지 | unknown | 사람 결정 |
| 캐스터 모델 · 바퀴 지름 | 바닥 프로파일에 다는 캐스터 4개 | unknown | 제품 선정. 브레이크 여부 포함 |
| 포트 높이 · 케이블 관통 위치 | 주입(오른쪽 옆면)과 배기(왼쪽 옆면)의 높이, 케이블 관통부의 면과 위치 | unknown | 자극 장비 배치와 천장 SEN55까지의 케이블 경로 |
| `inlet_dia` `exhaust_dia` | 주입 · 배기 구경 | dependent | 자극 장비의 실제 토출구, 요구 유량, 압력손실, 누설 시험 결과 |
| `cable_dia` | 케이블 관통 구경 | dependent | 선정된 케이블의 외경 |
| `sen_L` `sen_W` `sen_T` | SEN55 모듈 외형 | unknown | SEN5x 데이터시트가 담고 있는 값이다. `wiki/topics/SEN55.md`에 외형 치수를 인제스트해 넣으면 바로 확정된다 |
| `sen_r` | 천장 중심에서 각 SEN55까지의 거리 | unknown | 사람 결정 |
| `sen_phi` | 120° 배치에서 첫 대가 놓이는 방향 | unknown | 사람 결정 |
| `sen_gap` | 천장 부착면에서 모듈을 띄우는 거리 | unknown | 브래킷 형상과 함께 결정 |
| `elec_W` `elec_D` `elec_H` | 상판 외부 전장 공간 | unknown | 자체 PCB 크기가 정해진 뒤 전장함을 정한다 |

`pack_*`이 첫 단추다. 팩 치수가 정해지면 여유를 얹어 내부 유효 치수가 나오고, 골조와 패널을 얹어 외형이 나오고, 도어 개구가 팩과 반입 여유에서 나온다. 이 사슬의 맨 위가 비어 있는 동안에는 어떤 부품도 모델링을 시작할 수 없다.

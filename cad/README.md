# 지표 3 모의장치 제작 도면

정량적 성과지표 지표 3의 검수 시연에 쓸 모의장치를 실제로 만들기 위한 SolidWorks 도면과 그 원본 모델을 둔다. 장치가 무엇이고 왜 그렇게 구성되는지는 `wiki/topics/모의장치.md`가 서술하고, 이 디렉터리는 그것을 제작 가능한 형상과 치수로 옮긴다.

## 계층에서의 위치

저장소 루트 스키마 문서(`CLAUDE.md`)의 3계층 바깥에 있는 네 번째 계층이다. 근거는 한 방향으로만 흐른다.

```
raw/ (원문) · 사용자 확인  →  wiki/ (서술)  →  cad/ (형상·치수)
```

- `cad/`는 위키의 근거가 아니다. 도면이 정한 수치를 위키 페이지에 옮겨 적지 않는다. 위키의 근거는 인제스트된 원문과 사용자 입력 둘뿐이라는 스키마 규칙이 그대로 적용된다.
- 반대로 이 디렉터리의 모든 확정 치수는 위키에 이미 서술된 사실이거나, 사용자가 직접 결정한 값이어야 한다. 근거 없는 값을 도면에 채우지 않는다. 정해지지 않은 것은 정해지지 않은 채로 둔다.
- 작업 이력은 `log.md`에 남기지 않는다. `log.md`의 연산자는 `ingest` · `query` · `lint` 셋뿐이고 위키의 이력만 담는다. 이 디렉터리의 이력은 git 커밋과 도면 안의 개정란이 담는다.
- 위키링크(`[[…]]`)를 쓰지 않는다. 위키 밖에서는 해결되지 않는 죽은 링크가 되므로 `wiki/topics/모의장치.md`처럼 경로로 가리킨다.
- 개인 연락처와 계약 금액은 여기에도 전사하지 않는다. 부품 조달가와 견적은 제작에 필요한 정보이므로 이 계층에 둘 수 있다.

## 디렉터리

| 경로 | 담는 것 |
|---|---|
| `params/` | 치수의 단일 출처. SolidWorks 방정식 링크 파일과 값마다의 근거 대장 |
| `templates/` | 도면 양식(`.DRWDOT`)과 시트 포맷(`.SLDDRT`). 표제란·개정란·투상법·단위를 여기서 한 번만 정한다 |
| `parts/` | 부품 파일(`.SLDPRT`) |
| `assy/` | 조립품 파일(`.SLDASM`) |
| `drawings/` | 도면 파일(`.SLDDRW`) |
| `export/` | SolidWorks 없이 볼 수 있는 산출물. PDF · DXF · STEP |

하위 폴더를 더 만들지 않고 각 폴더 안에 평평하게 둔다.

## 도면번호와 개정

도면번호는 `J3-<대상 2글자>-<3자리>` 형식이다. `J3`은 지표 3, 대상 코드는 `CH`가 챔버, `SN`이 SEN55 관련이다. 새 대상이 생기면 이 표에 코드를 먼저 추가하고 번호를 뗀다.

파일명은 `<도면번호>-<한국어 이름>` 이며 공백을 쓰지 않는다. 예: `J3-CH-001-챔버-3면도.SLDDRW`.

원본 파일명에는 개정 문자를 붙이지 않는다. 원본은 언제나 최신 상태 하나이고, 개정 이력은 도면 안의 개정란과 git 이력이 담는다. `export/`의 산출물에만 `_REV-A`처럼 개정 문자를 붙여 어느 판이 발주처로 나갔는지 남긴다.

개정 문자는 **도면이 대상물에 대해 주장하는 내용이 바뀔 때** 올린다. 치수, 사양, 관통부 구성, 그리고 도면에 인쇄되는 명칭과 주기 문안이 여기 해당한다. 지시선 정리나 뷰 위치 조정처럼 표기만 손본 변경은 올리지 않는다. 새 도면은 `REV A`에서 시작한다.

## 좌표계와 단위

- 단위는 mm, 각도는 도(°)다.
- 원점은 챔버 **내부 바닥의 도어측 좌측 모서리**이며 Z-up이다. `x`는 폭, `y`는 깊이, `z`는 높이다.
- 투상법은 제3각법이며 도면 양식의 표제란에 표시한다.

## 치수의 단일 출처

치수를 스케치에 직접 박아 넣지 않는다. `params/chamber.txt`에 전역 변수로 두고 SolidWorks 방정식 대화상자에서 이 파일을 링크해 쓴다. 부품·조립품·도면이 같은 파일을 보고 있어야 값 하나가 바뀔 때 셋이 함께 따라온다.

값마다의 상태와 근거는 `params/chamber.md`가 담는다. 상태 어휘는 셋이다.

- `fixed` — 근거와 함께 확정된 값. 도면에 그대로 들어간다.
- `dependent` — 아직 값은 없지만 무엇이 정해지면 따라 정해지는지가 분명한 값. 도면에는 종속 조건을 적고 수치를 지어내지 않는다.
- `unknown` — 근거도 종속 조건도 아직 없는 값. 결정을 기다린다.

## 내보내기

도면을 개정할 때마다 `export/`에 PDF와 DXF를 함께 낸다. PDF는 발주사·제작처가 보는 판이고, DXF는 SolidWorks가 없는 환경에서 도면 내용을 실제로 검증할 수 있는 유일한 통로다. 3D 형상을 넘길 일이 생기면 STEP(AP214)을 같은 자리에 둔다.

## git

SolidWorks 원본(`.SLDPRT` · `.SLDASM` · `.SLDDRW` · `.DRWDOT` · `.SLDDRT`)을 전부 커밋한다. 바이너리라 저장할 때마다 파일 전체가 새로 쌓이지만 이 규모에서는 감당된다. `.git`이 수백 MB로 커지면 그때 Git LFS를 붙인다.

잠금·백업·자동복구 파일은 `.gitignore`가 걸러낸다. 커밋 전에 `git status`로 임시 파일이 섞이지 않았는지 본다.

## 지금 정해지지 않은 것

이 디렉터리는 비어 있는 상태로 시작한다. 챔버의 어떤 치수도 아직 확정되지 않았다. 위키는 장치의 구성과 제약을 서술하지만 mm 단위 수치는 한 곳에도 담고 있지 않다. 무엇이 정해져야 첫 스케치를 시작할 수 있는지는 `params/chamber.md`에 항목별로 적었다.

# 지표 3 ESS 모의 챔버 3D 모델

`design/drawings/chamber_params.json`을 2D 도면과 공유하는 파라메트릭 3D 모델이다. 확정된 3.0 mm 판재 두께를 반영한 **외형 셸**과 내부 유효 체적 경계면을 함께 표현한다. OBJ/MTL은 검토용 주 산출물이고 ASCII STL은 CAD·프린트 도구 반입을 위한 보조 산출물이다.

## 재생성

저장소 루트에서 Python 3 표준 라이브러리만으로 실행한다.

```sh
python3 design/models/gen_chamber_3d.py
```

생성기는 `chamber.obj`, `chamber.mtl`, `chamber.stl`을 덮어쓰고 9종 회귀 검사를 실행한다. 치수 변경은 `design/drawings/chamber_params.json`의 근거·상태와 함께 승인된 경우에만 반영하고 2D와 3D 생성기를 모두 다시 실행한다.

## 좌표계와 단위

원점은 챔버 **내부 바닥의 도어측 좌측 모서리**다. `x=폭(W_in)`, `y=깊이(D_in)`, `z=높이(H_in)`, 단위는 mm이며 Z-up이다. 외형 셸은 각 축의 내부 경계보다 판 두께 3.0 mm만큼 바깥에 있다. 원점의 빨강 X, 초록 Y, 파랑 Z 축 마커가 방향을 표시한다.

## 그룹

외형 셸, 내부 유효 체적, 받침 프레임, 각 팩, 전장 설치 공간, 도어 개구, 관찰창, 도어 손잡이, 공용 주입 포트, 배기 포트, 케이블 관통 포트, 센서 3점, 축 3개를 17개 OBJ 그룹으로 분리한다. 상부 센서 3점은 SEN55다. 외부 5분기 매니폴드는 챔버 밖이므로 모델링하지 않는다.

## 전장 설치 공간 (제안, 사람 미승인)

`electrical_envelope` 그룹은 챔버 **내부**에 전장 기기가 들어갈 공간을 나타내는 경계 상자다. 함체 형상이 아니라 확보해야 할 설치 공간이며, 내부 기기 배치·배선·상세는 확정하지 않는다. `300 × 150 × 120 mm`를 `(0, 940, 630)`에 두어 좌측벽·후벽·상판 세 면에 밀착시킨다. 공용 주입 포트가 있는 후방 쪽 모서리를 택한 2026-09-04 사람 지시와 「천장에 붙인다」 지시를 함께 반영한 위치다. 값은 전부 `status: "proposed"`이고 사람 미승인이므로, 검사 9는 이 상태가 유지되는지도 함께 확인한다.

검사 9는 공간이 내부 유효 체적 안에 있는지, 팩과 3차원으로 간섭하지 않는지, 어느 면에 밀착하는지를 보고한다. 검사 7의 자유 공간은 팩에 더해 이 공간까지 뺀 `0.518850 m³`이며, 2D 도면 `design/drawings/README.md`의 값과 같다. DEC 분사량 상한식에는 기존 `0.524250 m³`가 아니라 이 값을 쓴다.

확정값과 충돌하는 지점이 셋 있고, 지우지 않고 남긴다. 첫째, `clearance.top` 400 mm 구간(z 350–750)의 z 630–750 을 점유한다 — 이 여유의 `source`는 "상부 감지기 설치 공간"이다. 둘째, `clearance.rear` 150 mm 전부(y 940–1,090)를 점유한다 — `source`는 "전후 기류 공간"이다. 셋째, 챔버 내부는 IP55 밀폐·DEC 약품 분무·목표 60 ℃ 환경이라 전장 기기 노출 적합성이 확인되지 않았고, 기존 미해결 사항인 SEN55 절대 최대 50 ℃ 초과와 함께 사람 검토가 필요하다.

## 확정 치수와 개념 표현

외형 셸은 내부 유효 치수에 각 방향으로 판 두께를 더한 여섯 면이다. 모서리 접합, 용접 개선, 플랜지, 절곡 R은 근거가 없어 모델링하지 않는다. 받침 프레임은 승인된 높이 100 mm만 사용한다. 다리 개수·굵기와 상판 두께는 미정이므로 하부 100 mm 구간을 채우는 **표현용 단일 블록**이며 제작 형상이 아니다. 팩은 이 블록의 상면에 놓인다.

도어 개구는 600 x 500 mm로 내부 폭 가운데에 놓고 바닥에서 시작한다. 관찰창은 400 x 300 mm로 가운데 정렬하며 바닥에서 150 mm 올린다. 세로 손잡이는 길이 150 mm이고 도어 우측 가장자리에서 안쪽 40 mm에 중심선을 둔다. 손잡이 폭은 승인값이 없어 화면 식별만 가능한 얇은 평면 마커로 표시하며 제작 폭이 아니다.

동일 평면의 겹침을 피하려고 도어·관찰창·손잡이와 포트 마커를 내부 최소 치수의 0.1%만큼 챔버 안쪽으로 띄운다. 이는 **표시용 오프셋이며 제작 치수가 아니다.** 포트는 구경 없는 평면 사각 마커다. 마커 한 변의 절반은 내부 최소 치수의 2.5%이고 센서는 그보다 작은 교차 마커다. 이 크기는 가시성과 회귀 검사만 위한 것이며 구경·센서 외형을 뜻하지 않는다.

포트와 센서 마커의 이름과 개수는 파라미터 키에서 생성한다. 위치는 JSON의 구역 의미와 2D 배치 선례를 상대 좌표로 나타낸다. 공용 주입은 후면측 중·하부, 배기는 반대편 정면측 상부, 케이블 관통 포트는 측면 하부다. 케이블 관통 포트의 최저점은 프레임 간섭을 피하도록 받침 프레임 상면 이상에 둔다. 현재 공용 주입 포트 중심은 팩 상단보다 낮으므로 시료 상부 감지 구역 통과는 챔버 내측 노즐 방향에 의존한다.

축 마커 길이와 폭은 내부 최소 치수의 16%, 1.2%로 정한 화면 식별용 지오메트리이며 챔버 부품이 아니다. 센서 최소 이격 검사는 확정 간격이 없으므로 개념 포트 마커 지름 이상 떨어지는지만 확인한다.

다음 값은 근거가 없어 계속 비워 둔다.

- 공용 주입, 배기, 케이블 관통 포트의 구경 3종
- 노즐 각도와 분사 궤적
- 센서 최종 좌표와 확정 최소 이격
- 관찰창 재질·두께·내열·내화학 사양
- 프레임 다리 형상

판재 두께, 재질, 밀폐 등급, 도어·관찰창·손잡이 치수, 여유 치수와 내부·외형 치수는 `status: "fixed"`인 값만 사용한다. MTL의 색과 투명도는 그룹 구분용이며 판재의 물리 재질 지정이 아니다.

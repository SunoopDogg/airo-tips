# 지표 3 ESS 모의 챔버 3D 모델

`design/drawings/chamber_params.json`과 `design/drawings/sen55_params.json`을 2D 도면과 공유하는 파라메트릭 3D 모델이다. 확정된 3.0 mm 판재 두께를 반영한 **외형 셸**과 내부 유효 체적 경계면을 함께 표현한다. OBJ/MTL은 검토용 주 산출물이고 ASCII STL은 CAD·프린트 도구 반입을 위한 보조 산출물이다.

## 재생성

저장소 루트에서 Python 3 표준 라이브러리만으로 실행한다.

```sh
python3 design/models/gen_chamber_3d.py
```

생성기는 `chamber_params.json`과 `sen55_params.json` 두 파일을 읽는다. 입력 경로는 각각 `--params`, `--sen55-params`로 지정할 수 있다. `chamber.obj`, `chamber.mtl`, `chamber.stl`을 덮어쓰고 9종 회귀 검사를 실행한다. 치수 변경은 해당 파라미터 파일의 근거·상태와 함께 승인된 경우에만 반영하고 2D와 3D 생성기를 모두 다시 실행한다.

## 좌표계와 단위

원점은 챔버 **내부 바닥의 도어측 좌측 모서리**다. `x=폭(W_in)`, `y=깊이(D_in)`, `z=높이(H_in)`, 단위는 mm이며 Z-up이다. 외형 셸은 각 축의 내부 경계보다 판 두께 3.0 mm만큼 바깥에 있다. 원점의 빨강 X, 초록 Y, 파랑 Z 축 마커가 방향을 표시한다.

## 그룹

외형 셸, 내부 유효 체적, 받침 프레임, 각 팩, 챔버 외부 전장 설치 공간, 도어 개구, 관찰창, 도어 손잡이, 공용 주입 포트, 배기 포트, 케이블 관통 포트, 센서 3점, 축 3개를 17개 OBJ 그룹으로 분리한다. 상부 센서 3점은 천장면 정삼각형으로 배치한 SEN55이며 실제 외형 치수의 여섯 면 상자로 표현한다. 외부 5분기 매니폴드는 챔버 밖이므로 모델링하지 않는다.

## 전장 배치 — 챔버 상단 외부

챔버 내부에는 SEN55 3대만 두고 ESP32-S3-WROOM-1·PCA9548A 등 전장은 챔버 상단 외부에 둔다 (사용자 확인 2026-09-07). `electrical_envelope_exterior` 그룹은 외부 상판 중앙의 `300 × 150 × 120 mm` 설치 공간을 나타내며, 사용자 승인 2026-09-07로 `status: "fixed"`다. 실제 전장함은 미선정이므로 이 공간에 들어갈 기기 선정은 별건이다. 함체 부착 방식·브래킷·배선 경로는 확정하지 않는다.

좌우·전후 오프셋은 파라미터에 두지 않고 외형 치수에서 중앙 계산으로 구한다. 설치 공간 경계는 `(225, 470, 753)`–`(525, 620, 873)` mm다. 검사 9는 밑면이 외형 상면 이상인지, 평면 투영이 외형 바닥 면적 안에 들어가는지, 평면 중심이 외형 평면 중심과 일치하는지, 팩과 3차원 간섭이 없는지를 확인한다.

검사 7의 내부 자유 공간은 내부 체적 `0.613125 m³`에서 팩 체적 `0.088875 m³`만 뺀 `0.524250 m³`이며, `design/drawings/README.md`의 값과 같다. 전장 설치 공간은 챔버 외부이므로 차감하지 않는다. DEC 분사량 상한식도 `0.524250 m³`를 쓴다.

챔버 내부 제안이 폐기되면서 `clearance.top` 400 mm와 `clearance.rear` 150 mm를 전장 공간이 잠식하던 문제, 챔버 내부 IP55·DEC 분무 환경에 전장 기기를 노출하던 문제가 해소되었다.

남는 충돌은 `ports.cable_entry`의 `side-lower-separated` 배치(측면 하부, 2026-09-02 사람 결정)와 전장 상단 외부 배치다. 이 조합은 케이블이 챔버 밖을 따라 내려갔다 상부 센서 3점으로 다시 올라가게 되어 I2C 10 cm 권고 초과 문제를 키운다. 어느 쪽을 바꿀지는 사람 결정이므로 양쪽 배치는 유지하며 실제 배선 경로는 미정이다.

다습·고온 조건의 실제 도달 온습도는 아직 측정되지 않았다. 조건 조성 후 챔버 안 온습도를 실측하는 것이 첫 순서다. SEN55 권장 범위 10–40 ℃ / 20–80 %RH와 절대 범위 −10–50 ℃ / 0–90 %RH·결로 금지 조건을 넘으면 가습기·열풍기 세기나 센서 위치를 조정한다.

## 확정 치수와 개념 표현

외형 셸은 내부 유효 치수에 각 방향으로 판 두께를 더한 여섯 면이다. 모서리 접합, 용접 개선, 플랜지, 절곡 R은 근거가 없어 모델링하지 않는다. 받침 프레임은 승인된 높이 100 mm만 사용한다. 다리 개수·굵기와 상판 두께는 미정이므로 하부 100 mm 구간을 채우는 **표현용 단일 블록**이며 제작 형상이 아니다. 팩은 이 블록의 상면에 놓인다.

도어 개구는 600 x 500 mm로 내부 폭 가운데에 놓고 바닥에서 시작한다. 관찰창은 400 x 300 mm로 가운데 정렬하며 바닥에서 150 mm 올린다. 세로 손잡이는 길이 150 mm이고 도어 우측 가장자리에서 안쪽 40 mm에 중심선을 둔다. 손잡이 폭은 승인값이 없어 화면 식별만 가능한 얇은 평면 마커로 표시하며 제작 폭이 아니다.

동일 평면의 겹침을 피하려고 도어·관찰창·손잡이와 포트 마커를 내부 최소 치수의 0.1%만큼 챔버 안쪽으로 띄운다. 이는 **표시용 오프셋이며 제작 치수가 아니다.** 포트는 구경 없는 평면 사각 마커다. 포트 마커 한 변의 절반은 내부 최소 치수의 2.5%다. 이 크기는 가시성과 회귀 검사만 위한 것이며 구경을 뜻하지 않는다.

포트 마커와 센서 상자의 이름과 개수는 파라미터 키에서 생성한다. 포트 위치는 JSON의 구역 의미와 2D 배치 선례를 상대 좌표로 나타낸다. 공용 주입은 후면측 중·하부, 배기는 반대편 정면측 상부, 케이블 관통 포트는 측면 하부다. 케이블 관통 포트의 최저점은 프레임 간섭을 피하도록 받침 프레임 상면 이상에 둔다. 현재 공용 주입 포트 중심은 팩 상단보다 낮으므로 시료 상부 감지 구역 통과는 챔버 내측 노즐 방향에 의존한다.

센서 3점은 천장면 정삼각형으로 배치한다. 외접원 R250 mm, 중심은 내부 평면 중심 `(375, 545)` mm이며 꼭짓점 하나가 후방을 향하고 한 변은 약 433 mm다. 좌표는 `sensor_layout.circumradius`와 내부 치수에서 계산한다. 모듈 외형은 SEN55-SDN-T `52.3 × 43.3 × 22.3 mm`이며 `status: "fixed"`인 `design/drawings/sen55_params.json`에서 읽는다 (출처: [[SEN55]], Sensirion SEN5x Datasheet). 길이 x·폭 y·두께 z의 축 대응은 2D 평면도·상세도 배치를 따른다. 상면을 천장면에 맞춘 것은 표현용이며 천장면에서 띄우는 실제 거리와 브래킷은 미정이다.

팬 개구부·커넥터·라벨은 흡입구 위치가 `unknown`이고 모듈의 수직축 회전 방향에 근거가 없어 모델링하지 않는다.

축 마커 길이와 폭은 내부 최소 치수의 16%, 1.2%로 정한 화면 식별용 지오메트리이며 챔버 부품이 아니다. 검사 5는 센서 상자 전체의 내부 유효 체적 포함, 상자 사이 3차원 비간섭, 동일한 z 구간과 파라미터 키 일치를 확인하고 상자 사이 최소 간격을 출력한다. 중심점이 내부에 있는지도 함께 본다.

다음 값은 근거가 없어 계속 비워 둔다.

- 공용 주입, 배기, 케이블 관통 포트의 구경 3종
- 노즐 각도와 분사 궤적
- 천장면에서 센서를 띄우는 거리와 브래킷 형상
- 모듈의 수직축 회전 방향(팬 배출구·커넥터·라벨이 향하는 방향)
- 관찰창 재질·두께·내열·내화학 사양
- 프레임 다리 형상

판재 두께, 재질, 밀폐 등급, 도어·관찰창·손잡이 치수, 여유 치수와 내부·외형 치수는 `status: "fixed"`인 값만 사용한다. MTL의 색과 투명도는 그룹 구분용이며 판재의 물리 재질 지정이 아니다.
